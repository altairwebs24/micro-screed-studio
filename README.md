# Micro Screed Studio

Make a 5 page website with booking form  for Micro Screed Flooring, with the first image being the logo, and the second image on the hero section, with a mix of creative fonts, then use the rest of the media for display and add them under projects, bookings should take fill the form and redirect to WhatsApp with a prefilled message from the form, make sure you use a public storage bucket for all media and information. Ensure vite.config.ts explicitly includes an initialized plugins array (plugins: [...]) in defineConfig so Cloudflare deployment tools can successfully modify it. Make it as human man as possible.
